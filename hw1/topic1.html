Linked List

A linked list is a linear data structure where elements are not stored in contiguous memory locations but are instead linked together using pointers. Each element in a linked list is called a node, which consists of two fields: the data itself and a reference (or link) to the next node in the sequence. Unlike arrays, linked lists do not have a fixed size, allowing for dynamic memory allocation where elements can be easily inserted or deleted without shifting the entire structure. The detriment to linked lists is that because they lack random access, finding a specific element requires traversing the list sequentially from the beginning of the list, making search operations slower than in a traditional array.
