Binary Search Tree

A binary search tree is a hierarchical, node-based data structure used for efficient data sorting, searching, and retrieval. In a binary search tree, each node can have a maximum of two children, and it strictly follows the ordering property where the left child's value is less than the parent's value, and the right child's value is greater. As long as the tree is balanced, there are about equal amount of branches on either side, then with each node in a search, the remaining nodes is cut in half. Creating a time complexity of O(log n) If data is inserted in a sorted order without balance controls, the tree can degrade into a linear chain, dropping its performance to O(n) unless self-balancing mechanisms are issued.
